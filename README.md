# Projeto LeilõesTDSat

## Sobre o Projeto
Sistema informatizado desenvolvido para gerir as rotinas de uma casa de leilões, permitindo o cadastro de produtos, controle de status e futuras listagens e vendas de itens leiloados.

## Tecnologias Utilizadas
- **Linguagem:** Java (NetBeans / Ant)
- **Banco de Dados:** MySQL
- **Versionamento:** Git e GitHub
